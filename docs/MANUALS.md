# 操作手册：从成功任务到按需复用

日期：2026-10-27。当前为开发源码功能，本机 6797/6798 尚未更新。
复用 Web/worker 0.17、SQL0018、工作站0.6.3/guest6；无新数据库迁移、依赖或桌面驱动。

## 使用流程

1. 在一个已完成的电脑任务中点击“生成操作手册”。首版接收单执行段、1—200条全部成功回执的任务；编译任务本身不能成为操作来源。
2. 填写手册名称和要保留的做法。可声明输入名称、说明和来源中的实际值，例如 `directory / 目录 / /home/agent`。这些实际值只用于本机精确匹配，模型只收到参数名称。
3. 点击“预览生成依据”。这一步不请求模型。检查预览中的用途、参数、应用身份和操作类型，再勾选确认生成草稿。
4. 草稿通过原 Task、模型账本、预算及未知费用复核链生成；不会执行桌面动作，也不会自动进入可用目录。
5. 在“操作手册”页面修改名称、检索说明及 Markdown 步骤，审阅后“保存并启用手册”。保存后的内容固定，重复同内容保存复用原记录；不同内容返回409。需要进一步修改已保存内容时，先形成新草稿；首版没有覆盖式编辑或版本合并。
6. 普通新任务先看到启用手册的名称、描述和参数。模型判断相关时调用 `load_manual`。也可以在手册下展开“用这份手册开始新任务”，显式指定手册、Agent、本次目标及通道。
7. 执行仍进入原 Agent 循环，重新观察电脑、选择本次目标、产生新动作回执并检查新任务的完成合同。手册提供方法，不继承旧操作结果、坐标、观察、审批或认证。

例如，原任务访问 `/home/agent`，保存的方法描述“打开文件管理器，聚焦地址栏，输入本次目录并核对新画面”。下次目录可以改变，输入值来自本次目标；缺少参数时询问用户。界面变化由模型结合本次截图/DOM判断，不依赖已撤回的控件编号。

## 执行与存储

```text
成功 Task 的确认回执
  → 本机白名单清洗 + 拥有者预览
  → 新的 manualCompilation Task
  → submit_manual → Task.result.manualDraft
  → 拥有者编辑、审阅、保存
  → settings[manual.<draftTaskId>]（固定内容，可启停）
  → 新任务 configSnapshot.manuals（固定目录及正文）
  → load_manual → 原 Agent 的截图/DOM/键鼠/审批/成果链
```

- 自动清洗不发送原目标原文、原始截图、页面全文、Shell命令、文件路径、非声明输入、历史坐标和控制引用。保留操作类型、应用WM_CLASS、普通快捷键及网站origin。用户填写的用途/描述是显式提交内容；仍须审阅。
- 来源的检查等级和人工参与标记分别保存。来源为 `model_reported` 时如实显示“模型报告完成”；手册不会被标记为跨任务执行已认证。
- `manualCompilation`只提供`submit_manual`工具，无法在生成过程中调用Shell、浏览器或桌面输入。一个来源同一时间只能有一个未结束的手册生成任务；相同请求键继续复用原Task，未知请求不会被新任务自动绕过。
- 安装中的启用手册在任务受理时固定。停用只影响后续任务；已受理任务继续参考原版本。缺失/未启用的显式手册拒绝受理。任务受理限制最多12份启用手册、正文合计64000字符，超过时要求停用未使用项，不静默裁掉目录。
- 完整正文初始不进模型上下文。加载后重建首条系统消息中的参考区，保持正文原文；普通历史压缩不会吞掉它。DBOS重放加载结果会恢复该集合，无新模型请求或加载动作重复记账。`manual_loaded`事件记录实际加载。
- 桌面专用任务允许读取手册，继续禁止Shell和网页工具。原观察失效、两张近期有效截图、控制接管、敏感操作审批和未知效果复核保持。
- `SKILL.md`下载只包含用途和操作说明，不包含本地Task身份、来源轨迹或授权。非英文名称使用中性机器名并在正文保留展示名称。导出是本地文本能力，不代表已经兼容全部社区插件生命周期、依赖和Skill资源文件。
- 新增API均要求拥有者登录；写接口检查同源，保存必须`reviewed=true`。新配置使用现有备份链保存，不执行手册内的代码或安装脚本。

## 已验证与剩余范围

证据入口：固定响应验收 `docs/evidence/manuals.json`；真实模型补验 `docs/evidence/manuals-live.json`。

- 4项新增单元与19项受影响工具/上下文单元通过。覆盖轨迹清洗、工具隔离、按需正文、固定目录、压缩保留及Markdown导出。
- 隔离PostgreSQL、真实0.6.3桌面、生产worker及独立Next网页完成整条链路。浏览器实际预览、生成、编辑、审阅、保存、下载和发起新任务；匿名/跨站/未审阅请求被拒绝，重复保存幂等，390px无横向溢出。
- 成功链共3个逻辑Task：来源、草稿、新执行。来源4个GUI动作已在前次试验完成，后续复制其数据库只补网页与执行尾段，没有重跑来源。成功链共13次本机固定响应、9个真实桌面动作，0云模型请求。
- 新执行中实际停用手册并重启worker，随后通过原确认入口继续。冻结正文恢复、加载事件不重复、使用本次观察ID；后续新任务拒绝选择停用手册。
- 首次固定响应夹具误按普通JSON解析图像工具结果，留下1个unknown尝试；第二次网页验收发现三个提交按钮缺少显式submit类型。原失败、回执及数据库保留；修复后只补成功来源的后续链路。首次隔离构建漏复制worker类型源码的失败日志也保留。

### 真实模型补验（2026-10-27）

- 沿用先前成功来源的 4 动作轨迹（本机固定响应）。真实 Sol 用 1 次请求生成带 `{{directory}}` 参数的草稿；检查正文后通过实际网页审阅保存，没有重发成功编译。
- 正例由普通新任务触发，没有指定 `manualId`。模型根据目录元信息主动调用 `load_manual`，再用 4 个真实 GUI 动作打开 `/tmp`；6 次模型请求全部成功。最终地址栏 `/tmp/`、窗口标题 `tmp - Thunar` 和截图内容一致，未调用 Shell 或浏览器操作。
- 首次误选容器中不存在的 `/home/agent/Downloads`，15 次请求/13 个 GUI 动作后模型明确报告未能核对，独立标题检查判失败。保留原 Task、回执、报告及截图；同容器无模型诊断确认现有目录可导航后，只补一个现有目录正例，原草稿及已保存手册保持。
- 共新增 3 个 Task、22 次真实请求、Task 账本内 17 个 GUI 动作，无新增 unknown。目录价格估算：草稿 $0.012764、缺失目录 $0.192093、正常目录 $0.054954，共 $0.259811；这些是本地估算，未与服务商账单结算。原历史 unknown 不受影响。
- 初次报告脚本查询了不存在的 input_tokens/output_tokens 列；改为读取 usage JSON 后复用已完成编译继续。原失败日志和 compile-audit.json 保留。补验只新增/修正测试代码，没有修改产品执行器。
- 本轮 4 项手册单元及类型检查通过；原有全量成功样本没有重跑。主预览 .env/数据库计数/进程保持；隔离 Web、worker 与容器已停止。

本轮证明一个简单目录导航场景的实际提炼、发现和参数变化复用，未证明多软件泛化。

尚未验收：更多真实模型样本、多应用/参数变化下的泛化、手册之间冲突处理。插件内Skill自动发现、资源/脚本打包导入及流程市场未包含在本增量。原Thunar有限计划与独立验证机制继续保留，手册不授予ready认证。

定向命令：`npx tsx --test tests/manuals.test.ts`；隔离纵向：`npm run test:manuals`。后者仅用本机固定响应。若此前已完成来源任务，可传入其`report.json`，在隔离副本续验余下部分。
