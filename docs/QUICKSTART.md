# 本机基础版使用说明

更新：2026-10-30。首次在新电脑安装时，先按 [换机开发指南](DEVELOPMENT-TRANSFER.md) 初始化独立数据库、配置、账号和桌面镜像。

## 打开与登录

启动 worker 与网页，打开 `http://localhost:6797`。使用自己创建的拥有者账号登录，在设置页填写模型服务、API Key 和默认模型。选择 **OwnDesk Assistant** 交办任务。

## 直接交办

例如：

> 打开我指定的公开网页，截图并读取正文，整理三条中文要点，保存为 summary.md，提供下载。遇到登录先叫我接管，交还后再继续。

点击“新对话”开始独立任务；完成后点击成果旁的“下载”。在“继续对话”中可要求修改已交付文件。

需要登录时，在任务详情点击“接管桌面”，等待控制权准备完成后输入；操作完填写说明并“交还”。只读观看不能输入。取消会先停止真实操作，等待页面显示“已取消”。

## 运行边界

- 开发方式运行 `npm run worker` 和 `npm run dev`；生产 Web 构建使用 `npm run build` 和 `npm run start`。
- 本机开发进程没有自动重启监督。日志和运行状态保存在各自设备的 `data/`，不会上传 Git。
- 模型服务地址必须从当前电脑及相应运行环境可达；其他电脑的回环地址不能直接沿用。
- 源码已实现截图/DOM、AT-SPI2、人工接管、成果、恢复与手册等能力；实际软件与模型效果仍按任务核对。
- 当前工作站预装 Chromium、文件管理器、终端与开发工具；办公套件、独立文本编辑器和 PDF 阅读器仍待补齐。
- 历史试验报告见 `docs/evidence/`。当前能力边界以 [实施状态](STATUS.md) 为准；真实 VPS、完整新版 Compose 与长期运行继续单独验收。
