# 真实伴侣端到端验收（36 项）

交接要求保留完整真实端到端门槛。公开仓库的历史文档引用原设备上的 `/workspace/e2e/full.mjs` 与 `b2a.mjs`，GitHub main 文件树及已获取的分支中没有这些文件。本文件配套 `tests/companion-live.ts`，重建可随仓库迁移的 36 项验收。历史报告保持各自的范围。

测试通过真实 HTTPS/HTTP 服务、登录浏览器、配置好的真实模型与真实 worker 执行；不注入模型替身、不直接修改数据库生成完成状态。每次创建独立合成 Agent，图片、记忆、任务文件全部为合成数据。测试会产生模型费用，沿用安装的定价与月预算。已有日常数据库应另外部署一套测试安装后执行。

```sh
# .env 中 APP_URL 指向测试安装，模型已经在该安装设置中配置。
export LIVE_E2E_INSTALLATION=disposable
export LIVE_E2E_MODEL=deepseek/deepseek-chat
export LIVE_E2E_OWNER_FILE=/private/test-owner.json
export LIVE_E2E_DIRECTORY=/private/evidence/companion-live
npm run test:companion:live
```

OpenAI 兼容服务可以使用 `custom/<model>`。主人文件格式与已有 UI 测试一致，包含 `email`、`password`，保存在仓库外或被忽略的本地目录。服务端模型凭据不交给测试脚本。

| 编号  | 验收                                                                     |
| ----- | ------------------------------------------------------------------------ |
| 1     | 浏览器登录、创建独立伴侣、打开聊天界面                                   |
| 2     | 人设及伴侣时区持久化                                                     |
| 3–6   | 真实回复、刷新保持、重说、编辑替换                                       |
| 7–12  | 手动添加/编辑/审计记录/撤销编辑/删除/撤销删除                            |
| 13–17 | 真实模型记住偏好、更新旧事实、换说法去重、从记忆回答、忘记事实           |
| 18–19 | 真实模型整理主题、保留细节、整次撤销恢复原笔记                           |
| 20–22 | 合成图片缩放及元数据移除、下载解码及像素、真实识图                       |
| 23–24 | 合成工牌同轮的独立文字偏好需要确认、拒绝候选；工牌信息不进入有效记忆     |
| 25–26 | 浏览器预览/取消不发消息、删图后沿用历史描述                              |
| 27–28 | 真实跑腿提议等待确认、拒绝后无任务                                       |
| 29–32 | 确认创建任务、重复确认去重、真实执行及成果字节、完成消息回到聊天且不重复 |
| 33–34 | 真实长期目标提议、拒绝后无目标启动                                       |
| 35    | 实际聊天接口处理合成危机求助                                             |
| 36    | 聊天及任务请求计入费用记录、月预算设置保持                               |

脚本按编号串行运行，每项执行前后写入 `report.json`。失败时保留已通过项、失败原因、待执行项以及合成聊天记录；只有 36 项全部完成时 `passed` 才为 true。失败后的整套重跑另建证据目录并保留旧结果。

浏览器打字节奏、复制、移动布局、PWA 安装及离线页继续使用 `test:companion:ui`；长期目标的实际多轮文件交接继续使用 `test:objectives:live`。桌面控制、渠道交接、版本切换及改进实验室仍按交接中的各自套件执行，发布前将所有证据一并审阅。真实 FCM 推送维持单独授权。
