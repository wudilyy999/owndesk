## 3. 主会话开始时的最小核查

1. 读取当前 AGENTS/STATUS、git 状态和正在处理的文件，确认有无主会话新改动。
2. 检查逐帧观察、坐标映射、最新图像策略是否已经实现；状态以实际代码为准。
3. 检查第一条任务的模型、动作、检查证据是否可提取，避免直接搬原始消息和秘密。
4. 选择一项原生 GUI 的最小可观察方案；在运行端解析当前控件/窗口，保留实际截图。
5. 输出本阶段通过条件，进行针对性验证；沿用已有授权，不重复询问已确认总体方向。

已知历史快照：应用 0.15.1-dev、SQL 到 0015、工作站 0.5.0/guest5。它仅用于接手定位；本说明没有重新确认今天服务在线。后续版本与迁移号按当前仓库实际状态决定。
