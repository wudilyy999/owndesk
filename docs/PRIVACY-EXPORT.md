日期：2026-10-30。仓库以私有方式创建，上传副本与原电脑的运行目录分开。

## 脱敏和使用边界

上传副本的文档及文字报告已移除原电脑用户名、主目录和机器路径。文档链接优先改为仓库内相对路径；本机截图的 Markdown 展示改为留存说明。原始文件继续保存在原设备，上传副本中的路径脱敏不代表重新运行了原实验。

真实配置值仅用于本机比对，扫描结果不记录密钥正文。测试中的保留域名、示例口令和专用夹具按测试逻辑保留；它们与原电脑真实配置分别核对。`.gitignore` 默认排除运行数据、密钥文件、数据库归档与测试截图。

第三方作者的版权、许可和准确来源保持。Git 提交使用 GitHub 账号对应的 noreply 邮箱，不使用本机个人邮箱。

源码更新通过 Git 同步。运行数据需要单独通过私有方式备份与恢复；原电脑的身份与数据没有因上传被删除。
